# Ronex para Windows

Instalador e atualizações do **Ronex para Windows**, o player para a sua própria lista.

**Baixar:** [Ronex-Windows-Setup.exe](https://github.com/wesley956/ronex-windows/releases/latest/download/Ronex-Windows-Setup.exe) (Windows 10 e 11, 64 bits).

Ao abrir o instalador, o Windows pode mostrar "O Windows protegeu o computador". Clique em **Mais informações** e depois em **Executar assim mesmo**. Depois de instalado, o Ronex se atualiza sozinho.

O Ronex não vende, não fornece e não hospeda listas, canais ou conteúdo. Termos de uso e privacidade: https://ronex.cruzjade080.workers.dev/termos
